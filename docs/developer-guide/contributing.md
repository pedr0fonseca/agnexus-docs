# Contributing Guidelines

How to contribute to agnexus platform and documentation.

## Overview

We welcome contributions to agnexus! This guide explains how you can help improve the platform.

## Ways to Contribute

### Documentation

- Fix typos and errors
- Improve clarity
- Add examples
- Update outdated information

### Marketplace

- Submit MCP server templates
- Improve template descriptions
- Share use cases
- Help others discover templates

### Bug Reports

- Report bugs through GitHub issues
- Include reproduction steps
- Provide error messages
- Share relevant logs

### Feature Requests

- Suggest new features
- Discuss improvements
- Share use cases
- Provide feedback

## Getting Started

### Documentation Contributions

1. Fork the repository
2. Make your changes
3. Submit a pull request
4. Wait for review

### Marketplace Contributions

1. Prepare your MCP server
2. Submit through the marketplace
3. Or contact us directly

Please read and follow our [Code of Conduct](/docs/developer-guide/code-of-conduct).
