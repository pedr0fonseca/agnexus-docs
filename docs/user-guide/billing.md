# Billing & Usage

Manage your account billing and monitor usage on agnexus.

## Overview

Your agnexus account includes billing management, usage monitoring, and subscription controls.

## Viewing Usage

1. Go to **Dashboard** → **Settings** → **Billing**
2. View your current usage:
   - Active servers
   - Resource consumption
   - API requests
   - Storage usage

## Subscription Management

### Current Plan

See your current subscription plan:
- Plan name and tier
- Resource limits
- Billing cycle
- Next billing date

### Changing Plans

1. Go to **Settings** → **Billing**
2. Click **"Change Plan"**
3. Select your new plan
4. Confirm the change

Changes take effect immediately. You'll be charged or credited proportionally.

### Canceling Subscription

1. Go to **Settings** → **Billing**
2. Click **"Cancel Subscription"**
3. Confirm cancellation

Your subscription remains active until the end of the billing period.

## Payment Methods

### Adding a Payment Method

1. Go to **Settings** → **Billing**
2. Click **"Add Payment Method"**
3. Enter your payment details
4. Save

### Updating Payment Method

1. Go to **Settings** → **Billing**
2. Click **"Update Payment Method"**
3. Enter new details
4. Save

## Billing History

View your billing history:
- Past invoices
- Payment history
- Download receipts

## Usage Limits

Each plan has usage limits. Monitor your usage to stay within limits:
- Server count
- Resource allocation
- API requests
- Storage
