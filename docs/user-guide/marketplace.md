# Marketplace

Discover and deploy pre-built MCP server templates from the agnexus marketplace.

## Overview

The marketplace is a curated collection of MCP server templates that you can deploy with one click. Browse by category, search for specific functionality, or explore featured templates.

## Browsing the Marketplace

1. Navigate to [Marketplace](https://agnexus.ai/marketplace) or click **"Marketplace"** in the dashboard
2. Browse available templates:
   - **Featured**: Popular and recommended templates
   - **Search**: Find templates by name or description

## Filtering Templates

Use filters to find what you need:

- **Deployable**: Only show templates with GitHub URLs (ready to deploy)
- **Public MCP**: Only show templates with public MCP server URLs (ready to use)

## Viewing Template Details

Click on any template to see:
- Full description (markdown supported)
- GitHub repository link
- Public MCP server URL (if available)
- Deployment instructions
- Example use cases

## Deploying from Marketplace

1. Find a template you want to use
2. Click **"Deploy"** button
3. Configure:
   - Server name
   - Environment variables (if required)
   - Resource allocation
4. Click **"Deploy"** to start deployment

## Favorites

Save templates for later:

1. Click the heart icon on any template
2. View your favorites in the **"Favorites"** section
3. Remove favorites by clicking the heart again

Note: Favorites require authentication. Log in to save your favorites.

## Contributing to the Marketplace

We encourage the community to help build the marketplace! You can:

- Submit your MCP server templates
- Improve existing template descriptions
- Share use cases and examples

The marketplace is a collaborative effort—we're building it together with the community, and we'll also be adding templates ourselves.
