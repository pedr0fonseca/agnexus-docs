# Welcome to agnexus

agnexus is a platform for deploying and managing Model Context Protocol (MCP) servers. Upload your MCP code, connect your GitHub repositories, or browse our marketplace—then deploy to production with one click.

## What is agnexus?

agnexus makes it easy to deploy MCP servers to production. Whether you're building a custom MCP server or using a template from our marketplace, agnexus handles the infrastructure, configuration, and deployment so you can focus on building great tools.

## Key Features

- **One-Click Deployment**: Upload code or connect GitHub and deploy in minutes
- **AI-Powered Configuration**: Automatic Dockerfile and configuration generation
- **GitHub Integration**: Automatic deployments on every push
- **Marketplace**: Discover and deploy pre-built MCP templates
- **Subdomain Access**: Each server gets its own clean subdomain
- **Subscription Plans**: Flexible plans from free to enterprise
